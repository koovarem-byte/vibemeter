# Партнёрства: тест «Проверь вайб с другом» в каналах

Идея: небольшим каналам о психологии и отношениях предлагаем не рекламу знакомств, а интерактив для подписчиков. Тест из 7 вопросов, без анкеты и регистрации, ответ на вопрос «насколько мы совпадаем» с парнем, подругой или мамой.

## Ссылка с меткой

Для каждого канала своя ссылка, чтобы видеть, кто реально приводит людей:

```
https://t.me/vibemeter_bot?start=vtp_МЕТКА
```

Метка: латиница, цифры, `_`, до 30 символов. Например `vtp_psy_anna`, `vtp_otnosheniya_pro`.
Результаты: команда `/sources` в боте (пришли · заполнили анкету · прошли тест).

## Что можно обещать, а что нельзя

- Можно: тест бесплатный, без анкеты, 7 вопросов, процент совпадения, картинка для сторис.
- Нельзя: «тысячи людей рядом», «найдёшь любовь» и любые цифры, которых нет в `/admin` и `/week`.
- Только 18+: в тесте есть галочка «Мне есть 18 лет», для подростковых каналов не подходит.

## Где искать каналы

- Психология отношений, самооценка, «как понять партнёра», женские блоги про отношения.
- Городские каналы своего города (Псков) — заодно двигают шкалу города.
- Размер 2–30 тысяч подписчиков: там чаще соглашаются на бесплатный интерактив.
