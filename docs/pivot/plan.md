# Поворот Вайбометра (черновик 16.11)

Почему меняемся: девушек 5% (12 из 217 анкет), из вчерашних новичков возвращается 1 из 47.
Знакомства без девушек не работают, а набрать их не получается.

Что у нас уже есть сильного:
- аудитория «Шах и чата» (@shahichat, 4,5K, ролики до 684K): разборы переписок «как шахматные партии» (?? зевок / ! / !!);
- готовая техника: бот, Mini App, игры, тесты с другом, рассылки, админка, VIP;
- база фактов об общении с источниками (`facts.py`, `docs/pivot/fakty.md`).

## Варианты (рекомендую 1)

### 1. «Шах и чат» в боте — тренажёр переписки (рекомендую)
Не нужны девушки: продукт для каждого, кто переписывается.
- **Разбор переписки**: кидаешь скрин или текст → бот ставит оценки ходам (?? / ?! / ! / !!), пишет «лучший ход» и итог партии. Это формат твоих роликов, люди уже его любят.
- **Задача дня**: реальная (обезличенная) переписка, выбери лучший ответ из 3 → рейтинг как в шахматах (Эло).
- **Факт дня** из `facts.py` + «попробуй сегодня» (например, задай уточняющий вопрос).
- **Дуэль**: два человека отвечают на одну ситуацию, голосуют остальные.
- Возврат каждый день: задача дня + серия (у нас уже есть серии и уровни).
- Вирусность: карточка «Мой рейтинг переписки 1450» для сторис (карточка уже есть).
- Нужна модель для разбора (Claude API) — платно по токенам; на старте можно ограничить число разборов.

### 2. Анонимные вопросы и игры с друзьями
Тест «Проверь вайб с другом» + «Тайная симпатия» + анонимные вопросы — делаем главным, знакомства убираем.
Плюс: работает в любой компании. Минус: конкуренция с ботами анонимных вопросов.

### 3. Знакомства по интересам без романтики (друзья, компании)
Минус: та же проблема с возвратами, нужна плотность людей в одном городе.

## Что не трогаем при повороте
Админку, рассылки, систему роста, стикеры, Mini App как оболочку, базу и деплой.
Старые пользователи (≈200 живых) получают рассылку «Вайбометр теперь …».
