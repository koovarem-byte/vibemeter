# Mini App «Шах и чат» — набросок (16.11)

Стиль: тёмный фон, зелёные акценты (как кнопки бота), шахматная тема, неоновые эмодзи набора.
Всё в одном приложении внутри Telegram, без анкеты. Пять экранов, нижняя панель:
**Игра · Топ · Факты · Профиль**.

## 1. Игра (главный экран)
```
┌────────────────────────────┐
│ ♟ Задача дня №37   🔥 3 дня│  ← серия
│ Рейтинг 128 · Разрядник    │
├────────────────────────────┤
│  ┌─ чат ────────────────┐  │
│  │ Она:                 │  │  ← переписка пузырями,
│  │ Меня повысили!! 🎉   │  │    как в Telegram
│  └──────────────────────┘  │
│  Твой ход:                 │
│  [ Норм                  ] │
│  [ Поздравляю! Как это…  ] │  ← 3 хода карточками
│  [ Теперь будешь пропад… ] │
└────────────────────────────┘
```
После хода — **анимация оценки** на весь экран: крупный значок `!!` (бриллиант),
`!`, `?!` или `??` (зевок), под ним одно предложение «почему» и источник,
затем «Лучший ход» и `+15` к рейтингу, летящий в шкалу.
Кнопки: «Следующая задача», «Скинуть другу», «Картинка для сторис».

## 2. Топ
Вкладки: **Сегодня · Неделя · Всё время**. Первая тройка на «пьедестале» с короной,
дальше список. Внизу закреплено «Ты — 14 место». Отдельно «Топ друзей» (кто пришёл
по твоей ссылке).

## 3. Факты
Лента карточек: факт → «что делать» → источник. Свайп вверх — следующий.
«Факт дня» сверху. Темы-фильтры: Переписка · Ссоры · Свидания · Дружба · Расставания.

## 4. Профиль
Рейтинг крупно + график по дням, звание, серия, решено N из M,
«Мои ходы»: сколько `!!`, `!`, `?!`, `??` (круговая диаграмма),
«Твой стиль»: например «Задаёшь вопросы — сильная сторона; спешишь с советами — слабая»
(по тегам задач). Достижения-значки.

## 5. Дуэль (позже)
Двое отвечают на одну задачу на время, кто лучше — забирает очки. Приглашение ссылкой.

## Карточка для сторис (9:16)
«Мой ход: !! Бриллиант» + кусок переписки + рейтинг + @vibemeter_bot — главный рост из TikTok.

## Эмодзи для набора (кастомные, неон, зелёные + свои цвета)
Оценки ходов (самое важное, у каждого свой цвет как в шахматных движках):
1. `!!` Бриллиант — бирюзовый/зелёный кристалл со знаками !!
2. `!` Хороший ход — зелёный
3. `!?` Интересный ход — салатовый (на будущее)
4. `?!` Сомнительно — жёлтый
5. `?` Ошибка — оранжевый (на будущее)
6. `??` Зевок — красный
7. «Лучший ход» — звезда/галочка

Игра и интерфейс:
8. Пешка, 9. Конь, 10. Ферзь, 11. Король/корона — звания (Новичок → Гроссмейстер)
12. Шахматная доска/«задача дня», 13. Рейтинг (стрелка вверх/график)
14. Кубок (топ), 15. Медали 1/2/3 место
16. Огонь (серия дней), 17. Лампочка (совет), 18. Мозг/книга (факт), 19. Лупа (источник)
20. Чат-пузырь (переписка), 21. Часы (дуэль/время), 22. Скрещённые мечи (дуэль)
23. Подарок/рукопожатие (позвать друга), 24. Колокольчик (напоминание)
25. Разбитое сердце (тема «расставания»), 26. Два сердца (тема «отношения»)
